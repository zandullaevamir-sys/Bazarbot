# Bazarbot

Qoraqalpog‘iston uchun marketplace interfeysi. Loyiha attached reference image asosida responsive, mobile-first landing/dashboard ko‘rinishida tayyorlangan.

## Ishga tushirish

`index.html` faylini brauzerda oching yoki GitHub Pages orqali deploy qiling. Hech qanday build tool talab qilinmaydi.

## Tarkib

- `index.html` — sahifa strukturasi va Uzbek marketplace kontenti
- `styles.css` — responsive dizayn va komponentlar
- `script.js` — til tanlash, navigatsiya va toast interaksiyalari
